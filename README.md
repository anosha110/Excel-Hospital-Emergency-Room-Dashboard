
# Excel Hospital Emergency Room Dashboard
An interactive Hospital Emergency Room Dashboard created in Microsoft Excel to analyze patient data and generate meaningful insights.


## 📊 Dashboard Preview

![Hospital Dashboard](Hospital%20Dashboard.png)

## 🛠️ Tools Used
- Microsoft Excel
- PivotTables
- Data Visualization
- Interactive Filters

## 📈 Key Metrics
- Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Admission Status
- Age Group Analysis
- Department Referrals
